# Amazon EKS Cluster Setup — Step-by-Step



> **Architecture:**
> EC2 Management Host → `eksctl` → AWS EKS Control Plane → Worker Nodes

---

## Step 1: Create EKS Management Host

First, create an EC2 instance that will be used to manage the EKS cluster.

### 1.1 Launch EC2

Go to **AWS Console → EC2 → Launch Instance**

Use:

```text
OS              : Ubuntu
Instance Type   : m7i-flex.large
Purpose         : EKS Management Host
```

### 1.2 Install kubectl

`kubectl` is the command-line tool used to communicate with the Kubernetes cluster.

```bash
curl -o kubectl https://amazon-eks.s3.us-west-2.amazonaws.com/1.19.6/2021-01-05/bin/linux/amd64/kubectl

chmod +x ./kubectl

sudo mv ./kubectl /usr/local/bin/

kubectl version --short --client
```

> **Note:** The above kubectl version is from the older setup instructions. For a new EKS cluster, use a currently supported kubectl version compatible with your EKS version.

---

### 1.3 Install AWS CLI

AWS CLI allows us to interact with AWS services from the command line.

```bash
sudo apt update

sudo apt install unzip -y

curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"

unzip awscliv2.zip

sudo ./aws/install

aws --version
```

Expected:

```text
aws-cli/2.x.x ...
```

### 1.4 Install eksctl

`eksctl` is a command-line tool that makes it easy to create and manage EKS clusters.

```bash
curl --silent --location "https://github.com/weaveworks/eksctl/releases/latest/download/eksctl_$(uname -s)_amd64.tar.gz" | tar xz -C /tmp

sudo mv /tmp/eksctl /usr/local/bin

eksctl version
```

Verify:

```bash
eksctl version
```

# Step 4: Create EKS Cluster Using eksctl

Now we create the actual Kubernetes cluster.

### Basic Syntax

```bash
eksctl create cluster \
--name <cluster-name> \
--region <region> \
--node-type <instance-type> \
--nodes-min 2 \
--nodes-max 2
```

---

## Option 1: Mumbai Region

For Mumbai:

```bash

--region region-name
--node-type instance-type
--nodes-min 2
--nodes-max 2 \ --zones ,

## Option 2: N. Virginia Region

For N. Virginia:

```bash

--name ashokit-cluster4 \
--region us-east-1 \
--node-type m7i-flex.large \
--zones us-east-1a,us-east-1b
```

# Step 5: Wait for Cluster Creation

Cluster creation can take several minutes.

The process looks like:

```text
                 AWS
                  │
                  ▼
              eksctl
                  │
                  ▼
          EKS Control Plane
                  │
          ┌───────┴───────┐
          ▼               ▼
      Worker Node      Worker Node
          │               │
          ▼               ▼
        Pods             Pods
```

`eksctl` creates and configures the required AWS resources for the EKS cluster.

# Step 7: Delete the Cluster After Practice

This is **very important for student labs** because EKS and related AWS resources can incur charges.

Delete the cluster:

```bash
eksctl delete cluster \
--name ashokit-cluster4 \
--region ap-south-1
```

For N. Virginia:

```bash
eksctl delete cluster \
--name ashokit-cluster4 \
--region us-east-1
```

Then verify in AWS Console that the resources created for the lab have been removed.
