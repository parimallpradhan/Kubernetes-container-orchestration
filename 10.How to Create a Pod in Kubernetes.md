## How to Create a Pod in Kubernetes

### Method 1: Using `kubectl run`

Create an Nginx Pod:

```bash
kubectl run nginx-pod --image=nginx
```

Check the Pod:

```bash
kubectl get pods
```

You should see:

```text
NAME         READY   STATUS    RESTARTS   AGE
nginx-pod    1/1     Running   0          10s
```

### What happened?

```text
kubectl run
     │
     ▼
Kubernetes API Server
     │
     ▼
Creates Pod
     │
     ▼
Worker Node
     │
     ▼
nginx-pod
     │
     ▼
Nginx Container
```

### Method 2: Using YAML — Recommended

Create `pod.yaml`:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
spec:
  containers:
    - name: nginx
      image: nginx
      ports:
        - containerPort: 80
```

Create the Pod:

```bash
kubectl apply -f pod.yaml
```

Check:

```bash
kubectl get pods
```

Get detailed information:

```bash
kubectl describe pod nginx-pod
```

### Delete the Pod

```bash
kubectl delete pod nginx-pod
```

### Best teaching sequence

```text
kubectl run nginx-pod --image=nginx
             ↓
       kubectl get pods
             ↓
      kubectl describe pod
             ↓
        kubectl delete pod
             ↓
          Pod YAML
             ↓
       kubectl apply -f pod.yaml
```

**Important:** In real projects, we normally don't create Pods directly; we use a **Deployment** to manage Pods.
